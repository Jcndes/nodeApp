Bem-vindo ao Projeto NodeApp 🚀

Este projeto tem como objetivo o desenvolvimento de uma aplicação moderna em Node.js, estruturada com boas práticas de arquitetura em Model–View–Controller (MVC). A solução integra múltiplas tecnologias, como MySQL para persistência de dados relacionais, MongoDB para armazenamento flexível de documentos e Redis para gerenciamento de sessões e autenticação de usuários.

O sistema foi projetado para oferecer segurança, escalabilidade e facilidade de manutenção. Conta com rotas dedicadas para cadastro e gerenciamento de usuários, autenticação com senhas criptografadas e suporte ao upload de arquivos.

Esta página tem como propósito apresentar e centralizar as funcionalidades do software em desenvolvimento, servindo como ponto inicial para interação com a API e para futura expansão em uma interface web completa.
